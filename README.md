# codex-app

Ένα απλό web app (και CLI) για καταγραφή ημερομηνιών υπηρεσίας, παρουσίας και κενού.

## Προαπαιτούμενα

- Python 3.8+

## Χρήση (Web)

### Εκκίνηση web server

```bash
python3 app/web_app.py
```

Άνοιξε τον browser στη διεύθυνση `http://localhost:8000` για να συμπληρώσεις τις ερωτήσεις:

- «Πότε θα κάνεις υπηρεσία;»
- «Πότε θα κάνεις παρουσία;»
- «Πότε θα πάρεις κενό;»

Οι απαντήσεις αποθηκεύονται στο `data/shifts.json`. Η σελίδα `/list` εμφανίζει τις αποθηκευμένες καταχωρήσεις.

## Χρήση (CLI)

### Καταχώρηση απαντήσεων

Εκτελεί το prompt flow:

```bash
python3 src/cli.py
```

ή ισοδύναμα:

```bash
python3 src/cli.py prompt
```

Θα εμφανιστούν οι ερωτήσεις:

- «Πότε θα κάνεις υπηρεσία;»
- «Πότε θα κάνεις παρουσία;»
- «Πότε θα πάρεις κενό;»

Οι απαντήσεις αποθηκεύονται στο `data/shifts.json`.

### Προβολή καταχωρήσεων

```bash
python3 src/cli.py list
```

Εμφανίζει τις αποθηκευμένες καταχωρήσεις.

## Παράδειγμα (Web)

1. Εκκίνησε τον server: `python3 app/web_app.py`
2. Άνοιξε `http://localhost:8000` και συμπλήρωσε τις ημερομηνίες.
3. Δες τις καταχωρήσεις στο `http://localhost:8000/list`.

## Παράδειγμα (CLI)

```bash
$ python3 src/cli.py
Πότε θα κάνεις υπηρεσία; 2024-06-15
Πότε θα κάνεις παρουσία; 2024-06-20
Πότε θα πάρεις κενό; 2024-06-25
Οι καταχωρήσεις αποθηκεύτηκαν στο data/shifts.json

$ python3 src/cli.py list
Καταχωρήσεις:
- service: 2024-06-15 (καταγράφηκε 2024-06-01T10:00:00)
- presence: 2024-06-20 (καταγράφηκε 2024-06-01T10:00:00)
- leave: 2024-06-25 (καταγράφηκε 2024-06-01T10:00:00)
```
